Python programming projects completed as part of Oasis Infobyte virtual internship

#Task 1: BMI Calculator
Description: Command-line Python program that calculates BMI and classifies it into health categories.

*Sample Run 1 (Normal):
Enter your weight (kg): 65
Enter your height (m): 1.7

Your BMI is: 22.49
Category: Normal

*Sample Run 2 (Underweight):
Enter your weight (kg): 45
Enter your height (m): 1.65

Your BMI is: 16.53
Category: Underweight

*Sample Run 3 (Overweight):
Enter your weight (kg): 78
Enter your height (m): 1.7

Your BMI is: 26.99
Category: Overweight
